# Pomodoro Timer 🍅⏱️

Um temporizador Pomodoro simples e eficiente para melhorar sua produtividade.

## Funcionalidades ✨
- Temporizador Pomodoro padrão (25 minutos de foco)
- Timer de pausa curta (5 minutos)
- Timer de pausa longa (15 minutos)
- Notificação sonora ao final de cada ciclo
- Interface limpa e intuitiva
- Responsivo (funciona em mobile e desktop)

## Como Usar 🚀
1. Acesse [https://github.com/vitorinojuliano/pomodoro-focus.git]
2. Clique em "Start" para iniciar o temporizador
3. Concentre-se na tarefa até o timer terminar
4. Faça uma pausa quando o alarme tocar
5. Repita o ciclo!

## Tecnologias Utilizadas 💻
- HTML5
- CSS3
- JavaScript
